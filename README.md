# 📸 Relive It – Reconnect Through Memories

**Relive It** is a smart, memory-focused photo app that helps you relive meaningful moments with friends—automatically. It detects faces in photos, identifies shared memories based on location and friends, and brings them back to you when it matters most.

> _Don't just store memories—relive them._

---

## 🚀 Features

### 🤳 Smart Face Detection & Auto-Sharing
- Detects friends' faces in photos and auto-shares them with those who were there.
- No manual selection needed—just capture and let the app do the rest.

### 📍 Memory-Based Notifications
- When two friends take a photo at a location and one of them revisits that spot later, the app sends a gentle memory reminder.
- Reconnect with friends and revive the emotion attached to the moment.

### 🗂 Event-Based Common Albums
- Share photos in real-time with friends during events (e.g., parties, trips, reunions).
- Create a shared album for each event and allow everyone to contribute to the same memory vault.

---
## 🛠 Tech Stack

- **Frontend:** UIKit (Swift)
- **Backend:** Supabase (PostgreSQL, Auth, Storage, Realtime)
- **Face Detection:** Vision Framework
- **Location Services:** Core Location
- **Photo Access:** PhotoKit
- **Push Notifications:** UserNotifications
- **Authentication:** Supabase OTP Auth (Phone Number + Name)
